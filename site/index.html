External AI, real control

Describe the edit.
Own the timeline.

Use a file-capable AI website or a coding agent in your project folder. It creates a documented FiveCut project package; the editor validates it, imports it, and keeps every decision editable.

01

Ask naturally

“Build a sharp 45-second creator intro, remove dead air, keep captions clean, and land the music on the reveal.”

02

Receive a project

The AI returns structured, deterministic JSON using FiveCut’s versioned schema—without needing a model inside the app.

03

Validate and finish

FiveCut checks files, hashes, timing, and capabilities before creating an undo-safe timeline ready to preview or refine.

FIVECUT PROJECT API

A stable editing language for agents.

Tracks, trims, captions, effects, keyframes, audio, assets, and export settings are explicit. Validation errors are readable; operations are logged and recoverable.
